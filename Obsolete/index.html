Skylark Obsolete

Skylark Obsolete covers issues caused by older software versions, unsupported platforms, or outside services that no longer work correctly on older devices.

Some older devices may not be able to join Skylark Servers because Dropbox or other services no longer behave the same way on older iOS and iPadOS versions. This is not fully controlled by Skylark.

Current issue

Some iOS 14 and iOS 15 users may not be able to join Skylark Servers through the Dropbox app. If the folder was added before Dropbox started cutting support, the user may still be able to access it. New users may see an error code or the Dropbox app may fail to load the folder.

General workaround

  1. Try using Dropbox on the web to add the folder.
  2. If your browser is unsupported, try using a computer.
  3. Use a newer device to add the folder, then sign into Dropbox on the older device.
