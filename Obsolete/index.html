Skylark Obsolete

Some older iOS and iPadOS versions may have trouble joining Skylark Servers. This is mostly affecting older software versions where Dropbox no longer works the same way it once did.

This is not fully controlled by Skylark. Some features depend on outside apps, browsers, services, or shortcuts behavior. If those services stop supporting older software, some Skylark features may stop working on those versions.

Current issue

iOS 14 and iOS 15 users may not be able to join Skylark Servers through the Dropbox app. If the folder was added before Dropbox started cutting support, the user may still be safe. However, new users may see an error code or the Dropbox app may fail to load the folder.

What you can try first

  1. Use Dropbox on the web to add the folder.
  2. Use a computer if your device browser is not supported.
  3. Use a newer device to add the folder, then log into Dropbox on the older device.
