Supported Files

Skylark supports a limited set of image file types to ensure reliability, compatibility, and consistent performance across supported devices.

Supported file extensions

  • .jpeg / .jpg — Recommended for most uses
  • .png — Higher quality, larger file size
  • .heic* — Supported, but may have limitations
HEIC files may occasionally have issues depending on the device, software version, or service being used. If a HEIC image fails to work, try redownloading the file or converting it to JPEG or PNG.

If your file is being rejected

If your file is not supported, or is being rejected, you can convert it into a supported format.

Open Skylark Image Converter

You may also use your own image conversion tools if you prefer.

If your file should work but doesn’t

If your file uses a supported extension and is still not accepted, this may be an issue Skylark does not expect.

In that case, please contact @SkylarkSupport.
