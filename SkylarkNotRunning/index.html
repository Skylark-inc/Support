Skylark not running, quitting unexpectedly, or endlessly loading

If Skylark is not opening, quits unexpectedly, or gets stuck loading, there are a few common causes and solutions you can try.

Possible causes

  • Back-to-back usage
    Running Skylark repeatedly in a short amount of time can cause iOS or iPadOS to slow it down. This may result in longer load times, freezing, or the shortcut quitting unexpectedly.

In many cases, simply waiting a few moments before running Skylark again will resolve the issue.

If Skylark does not run from the Home Screen

If Skylark does not run when launched from your Home Screen but works inside the Shortcuts app, restarting your device is the recommended fix.

You can restart your device directly through Skylark:

Settings → Tools → Restart Device
Skylark must be given permission to restart your device. Any unsaved data will be lost.

If Skylark does not run at all

If Skylark does not open anywhere, including the Shortcuts app, you will need to restart your device manually.

How to restart your iPhone or iPad

Alternative fix (no restart)

If you prefer not to restart your device, you can re-add Skylark:

Settings → Shortcut Updates → Re-add Skylark

Check your Skylark version

Issues may occur if you are using an outdated Edition or version of Skylark. Using the latest supported Edition ensures better stability and compatibility.

Bonus tip
